# Project Health Monitoring Application 🩺

A lightweight Python application designed to provide real-time resource usage monitoring (CPU, RAM, Disk) for ensuring the optimal health and performance of an associated project or service.

## ✨ Features

* **Real-time Metrics:** Reports CPU and Memory utilization every 10 seconds.
* **Simple Setup:** Minimal dependencies via `requirements.txt`.
* **Extensible:** Easy to modify to add database checks, API latency tests, etc.

## 🚀 Installation

1.  **Clone the Repository:**
    ```bash
    git clone [https://github.com/YOUR_USERNAME/Project-Health-Monitor.git](https://github.com/YOUR_USERNAME/Project-Health-Monitor.git)
    cd Project-Health-Monitor
    ```

2.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
    *(Requires Python 3.6+)*

## 🛠️ Usage

Simply execute the main Python script:

```bash
python monitor_health.py
